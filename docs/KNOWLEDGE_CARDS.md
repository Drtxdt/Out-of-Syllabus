# 知识与卡牌规则

科学知识通过可复核条件和反例体现。质量决定下落速度只能作为待检验假说；无空气阻力、同一重力场和相同初始条件下，加速度相同。

## 实验

统一高度 2 m、初速度 0 m/s、同时释放。无阻力用 t=sqrt(2h/g)，g=9.81 m/s²。有阻力用 Fd=0.5ρCdAv²，固定 0.001 s 中点积分，最多 120 s，落地时插值。纸片揉团改变面积；这是教学简化模型，不模拟翻滚、升力或复杂流体。

验证应比较无阻力质量独立性、空气阻力与面积影响、非法参数和重复证据。科学参考：[NASA 阿波罗 15 锤子与羽毛实验](https://science.nasa.gov/resource/the-apollo-15-hammer-feather-drop-2/)。

## 可见卡池

观察、基础实验固定可用，其余十张中选择六张：质量假说、重力模型、控制变量、实验测量、重复实验、反例检查、形状比较、真空对照、阻力修正、适用条件。未来数值积分单列，普通论证无法直接调用。

路径 A 用测量建立证据，路径 B 用重复实验建立证据。两条路线都需观察、控制释放条件和正确模型；最终遭遇还需形状/适用性、真空对照及阻力修正。重复同一测量不重复增加证据。

每回合两次有效行动，无效条件给提示并不扣除行动。最多八回合，预算耗尽允许重试。下一条确定性反例在论证界面提前显示，回合结束后结算。

## 设计欠项

当前解释度是明确布尔条件的匹配，不是自由文本理解。后续把每条 evidence 关联实验记录 ID 与条件快照，支持独立的预测偏差与矛盾列表。领域卡不能成为任意通行证；改小模型的有效域也不能移除遭遇的必需观察。新增高级卡必须先验证适用条件，再判断许可与代价。
