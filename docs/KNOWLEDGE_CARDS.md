# v0.3 动作与知识

| 动作 | 解锁 | 核心效果 |
| --- | --- | --- |
| 揉团 / 展开 | 教室实际操作 | 同一纸片改变面积与形状，质量不变 |
| 调高 / 齐放 | 配重示范 | 改变夹持高度、同 tick 释放；不保证同时到达 |
| 固定 | 双锤胜利 | 现有夹具保持物体；松开是基础退路 |
| 抽气 | 第三轮联合实验 | 改变介质，形状阻力优势随之失效 |
| 未来 | 档案室接受知识 | 预测窗口并走捷径，实际使用产生后果 |

动作 AP 与目标类型由 `content/v03/` Resource 及核心共同验证。攻击、防御、通道移动、松开、结束回合为基础指令。卡牌可复用，不设随机抽牌。

知识的发现、理解和许可分开记录；知道未来知识不代表被许可。模型适用性另行判断。实测含真实释放来源与读取事件，预测无法冒充观察；无已读实测不能走观察校准路径。
