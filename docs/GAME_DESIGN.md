# 超纲游戏设计

本作是一款章节式悬疑解谜 RPG。玩家先观察现象，再修正解释；过去自己的真实行动留在世界中，与本轮干预共同形成新结果。目标读者无需预先掌握公式，首次发布简体中文、单机离线、Windows 键鼠。

## Demo 范围

六个相连区域：教室、走廊、实验室、器材室、观测塔、封锁档案室。四名 NPC、十二张普通工具卡、一张未来知识卡、两场主要论证、一种环境威胁。不做经验刷怪、联网、随机抽牌或无限历史叠加。

第一轮观察：球与纸片提供不同下落现象，玩家准备实验并留下行动轨迹。第二轮反例：同形状不同质量接近同时落地，上一轮自己的机关操作帮助开启路线。第三轮条件：比较形状、空气和真空，两个历史回声仍按原轨迹行动。

当前灰盒已贯通上述路径，但普通机关可由一个人完成，尚未形成必须协调两个回声的最终装置谜题。这是接下来主要关卡工作，不能用增加空等时间替代。

## 现象与模型

现象界承担探索、观察、交流和实验。移动、短闪避与一种知识应用制造短暂危险，不惩罚性刷怪。模型界采用可见卡池和确定性反例，每轮两次行动，必须解释全部要求。真空假设不能删除空气中的观察。

每次失败依次提供观察建议、差异和具体问题；玩家可主动打开提示。当前提示由用户主动查看，自动分级和对应物体高亮列入交互迭代。

已理解流程可压缩，但所有时间内的历史命令仍逐个执行；环境改变立即停止压缩。错误操作可恢复区域或实验检查点。

## 叙事结尾

接受未来数值积分卡：提前完成预测，超纲度加一，监考者出现。拒绝：依靠实验和已建立模型完成本章。两个结尾都持久保存选择。当前表现为文字结尾，数值积分的可操作预测演出、监考者角色及场景演出尚未制作。

每章有完整的小结局。后续仅候选电路与测量、概率与证据，不提前制作尚未验收章节的全部内容。
