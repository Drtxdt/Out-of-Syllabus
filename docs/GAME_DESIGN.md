# v0.3 游戏设计现状

主线围绕“操作物体、看见结果、把动作带入战斗、遇到介质边界、与过去合作”推进。笔记提供回看，完成流程不要求填写旧版论证表。

纸片门阈值 0.74 秒，延时窗口 180 tick；巡逻纸偶支持攻击、防御和纸片遮挡/攻击取舍。双锤护盾由两个配重的到达差决定，可以调高，也可以利用敌方落锤降低支架。风箱纸偶先在空气中使用展开或揉团触发装置，后转入真空，需要改变高度而非继续依赖阻力差异。

第一轮 A 有效维持 480 tick，第二轮 A/B 真实重叠 360 tick。玩家准备后敲铃，倒数 180 tick；第三轮当前玩家操作 C。固定与器材室纸片障碍赋予第二轮独立操作目标。

未来路线省去器材室校准往返，玩家选择模型、参数并亲手释放闸门。错误模型保留计算反例。实际使用后才记违规；预警、追逐、被抓、重试与提交分别持久化。拒绝路线引用已有观察，能够独立完成。

参数为当前实现值，尚未通过真人盲测平衡。画面中部分占位资产明确标注；音画完成度、无提示可理解性和真人时长仍需外部试玩。
