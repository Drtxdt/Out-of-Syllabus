# 章节路线与开发队列

每周人工投入 8–12 小时，每两周保留可玩版本，同时只推进一个主要功能。时间建议 60% 内容玩法、25% 验证修复、15% 工具文档。以下是人工设计、审核和试玩预算，不以代码生成速度替代。

| 阶段 | 原始预算 | 当前状态 | 完成门槛 |
| --- | --- | --- | --- |
| M0 工具骨架 | 8–12 h | skills、固定引擎、Forge、骨架已落地，导出按验证报告 | 本机可重复导入、运行、测试与 Windows 导出 |
| M1 因果技术 | 35–55 h | 全图逻辑回放、偏差、恢复已实现 | 通过冲突、暂停、快进、压缩、存读档和实际输入测试 |
| M2 短闭环 | 45–65 h | 三轮灰盒可贯通 | 未读文档玩家完成10–15分钟闭环，知道模型为何失效 |
| M3 完整灰盒 | 80–110 h | 六区和两个结局已有骨架 | 有意义的双回声协作、完整叙事、45–60分钟实测 |
| M4 公开质量 | 40–60 h | 未完成 | 正式美术音效、性能存档压力、五人试玩与发布门槛 |

总计 208–302 h；含返工按每周投入仍约6–12个月。完成 M1 后以真实工时重估。已有代码不意味着这些人工验收自动完成。

## 下一项只做回声协作关卡

可玩结果：第三轮由前两轮操作分别维持供电与释放条件，当前玩家控制实验；改变历史机关可看见可解释偏差，错过时恢复检查点而无需空等。

验收：两段真实历史、三个角色行动都可在日志追溯；一个历史条件改变时实验不能假成功；两分钟内可恢复并重试。以此替换当前可由单人顺次开关完成的联锁门。

## 随后任务

1. 科学证据数据化：实验记录与论证强绑定，明确预测、观察、矛盾。验收：捏造真空条件不能过关。
2. 新玩家引导：区域标签、物体名称、按键映射、主动/被动三级提示、提前反例。验收：无文档完成10–15分钟流程。
3. 回声表现：语义动作动画、历史对话/拾取回忆、位置插值和房间切换。验收：不重复奖励且看得懂行动。
4. 可靠性：嵌套存档验证、故障注入、长循环压力、事件数量和内存预算。验收：恢复后结果与连续运行一致。
5. 单角色资产流水线：四方向少量动作，像素 QA 和引擎渲染通过后才批量。
6. 外部试玩：五人中至少四人独立完成并解释一次模型失效。记录卡关、无效等待和因果理解；不达标先改交互。

## 后续章节

下落与阻力 → 电路与测量 → 概率与证据。前章验收才进入下章详细制作；默认每章60–90分钟、6–10区域、2–3循环、最多一个新核心系统。各章都有小结局、长期进度检查点和存档迁移，不要求重打。

公开发布、商店、商业化是独立任务。当前不创建自动化、不上传构建、不发布商店；按实际生产能力决定更新周期。
