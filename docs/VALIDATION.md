# 灰盒验证报告

验证日期 2026-10-02，版本 v0.1.0。结果只代表当前机器和灰盒范围；尚未达到公开 Demo 验收。

## 已实际执行

- Godot 4.7.2 导入与脚本注册成功，退出码0。
- 核心回归 **94项检查全部通过**，结果 reports/regression.json。包含内容ID唯一性、科学计算、卡牌条件与重复证据、预算失败、跨房间回声、因果冲突、历史不可变、暂停、检查点、压缩中断、三个循环、两个结局、保存覆盖、损坏备份、schema 1迁移、未来版本拒绝、论证中途恢复及连续运行/存读档的语义一致性。
- GPU 场景测试通过：六个房间、三轮状态流、两场论证、结尾与恢复。该测试通过游戏方法驱动流程，不能代替真人按键完整通关。
- 1280×720、1920×1080、2560×1440 已实际生成截图；人工查看了世界、模型界等代表画面，中文字体正常，长面板可滚动。
- Forge MCP 完成编辑器连接与场景树读取、运行主场景、运行时树、真实按键输入、移动断言、截图和错误读取。报告 reports/forge.json；错误列表为空。新安装后重启编辑器解决了首次运行时桥未连接问题。
- 官方4.7.2 Windows x64 debug/release模板已安装，ZIP CRC验证和SHA256记录于 reports/templates.json。
- Windows release 导出成功；独立 EXE 已进行 headless 和实际 GPU 启动检查。实际 GPU 启动日志 reports/export-smoke.log，退出码0，无脚本错误。

## 修复记录

命令行导入和导出最初激活 Forge 编辑器服务器，退出时出现引用资源未释放报告。构建脚本现在采用插件官方的 GODOT_FORGE_NO_SERVER=1，最终导入与导出没有该错误，不修改上游插件。

确定性测试最初逐字比较 JSON，Godot JSON 解析会把整数恢复为浮点数，造成数值相同但字符串不同。现统一 JSON 数字表示后比较全部快照；没有放宽世界值、事件顺序或轨迹数量的检查。
