# 路线图

本轮只交付 v0.2 序章：实验必须产生证据、回声必须参与、超纲必须有实际后果。六区、三循环、两论证、双结尾保留。

| 阶段 | 实现结果 | 验收状态 |
| --- | --- | --- |
| S0 可信环境 | 路径可迁移、数据隔离、候选验证、备份恢复、严格失败 | 自动回归与异常存档测试；详见验证报告 |
| S1 实验与论证 | 固定条件实测、读取与引用、重复来源去重 | 两种合法证明和拒绝案例已覆盖 |
| S2 双回声 | A/B真实录制、C联合释放、断电与错过窗口 | 正常/快进/恢复/存读一致性与完整输入路线 |
| S3 后果 | 闸门预测与校准、追逐和局部重试、最终提交 | 两个结尾及被抓恢复路线 |
| S4 交互表现 | 中文独立UI、整数世界缩放、焦点与滚动 | 四窗口自动布局和实际引擎截图；正式资产未验收 |
| S5 交付 | 新Windows目录、绑定提交的报告 | 以最终导出与独立EXE结果为准 |

下一道人工门槛：邀请未读文档的玩家盲测，记录第一次释放、读取、论证、录制、错过窗口和追逐的卡点；让玩家解释一次模型失效及两条历史各自的贡献。尚无真人数据，不填写虚构时长或成功率。

全部门槛通过后继续卡序列枚举、命令不变量扩展、内容校验和正式试玩准备。测到具体问题后再优化，不为未知负载预先改造架构。正式美术先验收一个角色、实验室和论证桌，再补监考者与装置。

第二章暂不启动；公开发布、商店和商业化是独立任务。当前只生成本地可玩构建与本地提交。
