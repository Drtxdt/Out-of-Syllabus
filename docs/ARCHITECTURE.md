# v0.3 架构

当前主场景为 `app/v03/main.tscn`。旧 `app/main.tscn` 和 v0.2 核心保留，用于维护旧版本及回归。

- `core/v03/game_session.gd` 是唯一权威命令入口：阶段、对象、位置、拥有、AP、版本、去重及结算均在此检查。失败原子回滚；移动预算按 tick 累计。
- `physics.gd` 使用固定 1ms 积分生成轨迹。预览、近景、实测与验证共用结果；形状改变面积而不改变质量。预测独立保存。
- `combat_session.gd` 为纯动作求解器；内容 Resource 定义动作与遭遇。提交检查状态版本，UI 不修改战斗状态。结束回合求解本轮释放、装置效果和敌方动作。
- 局部回声片段保留原循环、事件、时间与位置。播放按历史顺序执行；离位、断电和失败释放持有。片段哈希与来源校验独立验证；快进逐 tick 执行。
- `save_validator.gd` 在候选状态上检查嵌套结构、轨迹、来源、观察事件、章节解锁、历史与检查点；`save_store.gd` 管理临时文件、有效备份、损坏隔离和未来版本拒绝。
- `guide_director.gd` 消费 `GoalDef` 资源与实际进度；闲置仅累计可操作世界时间。HUD、笔记、设置和战斗由 `ui/v03/` 展示与发送信号。

世界 640×360 整数缩放并留边，UI 独立中文布局。原 TileMapLayer 场景重用，动态物件位置及状态由核心投影。实际可玩的配置为固定手牌、可重复装置动作和基础退路，没有增加抽牌随机机制。

完整字段见 `V03_CONTRACTS.md`。历史架构见 `archive/v0.2/ARCHITECTURE.md`。
